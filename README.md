# Waleed Shammarez — Portfolio

A static, browser-based portfolio with a rainy game title screen and interactive project menu.

## Run locally

Open `index.html` in a browser. For the best results, serve the folder with any static web server.

## Deploy to Cloudflare Pages

1. Create a Pages project and connect this GitHub repository.
2. Choose **None** as the framework preset.
3. Leave the build command empty.
4. Set the build output directory to `.` (the repository root).
5. Deploy. No environment variables or backend are required.

The site is plain HTML, CSS, JavaScript, and static image assets. The main menu includes a direct resume link, and the character panel has email, phone, resume, and LinkedIn contact options.
